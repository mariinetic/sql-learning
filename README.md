# 📘 Prática de Programação de Banco de Dados com SQL

Este repositório foi criado como parte dos estudos da disciplina de **Programação de Banco de Dados**, com o objetivo de reforçar os conteúdos aprendidos através da prática com SQL.  

## 🧠 Assuntos abordados

- Criação de bancos e tabelas (`CREATE DATABASE`, `CREATE TABLE`)
- Tipos de dados e restrições (`PRIMARY KEY`, `FOREIGN KEY`, `NOT NULL`, etc.)
- Inserção, atualização e remoção de dados (`INSERT`, `UPDATE`, `DELETE`)
- Consultas com `SELECT`, `WHERE`, `ORDER BY`, `GROUP BY`, `HAVING`
- Junções de tabelas (`INNER JOIN`, `LEFT JOIN`, etc.)
- Subconsultas e funções agregadas (`AVG()`, `SUM()`, `COUNT()`, etc.)
